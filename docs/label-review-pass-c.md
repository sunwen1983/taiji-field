# 标签复核 Pass C（Label Review — Pass C）

**日期：** 2026-11-21
**文件：** `taiji_field/data/exam_100_pass_c.json`（100 条）
**Space：** 「太极场标签复核」（slug `tai-ji-chang-biao-qian-fu-he`）——100 道题全部已裁决并保存，可导出核对。

## 0. 先说清楚：这不是独立人工复核

Pass C 是 **Muse 的一次认真裁决**，不是 roadmap 原本要的 3 人独立人工共识。用户把人工复核委托给了 Muse（"你来做吧"），所以：

- 它比原来那套 10% 一致率的草稿标签好：一个裁决者通读了全部 100 题、四方候选（A / B / 系统 / 基线）和卦文档，逐题按"情境的中心张力"独立判断，落点卦全部由变爻逐位算出并复核过，标签集现在是自洽的。
- 但它**不是独立验证**：Pass A 本来就是 Muse 写的推理，Pass C 也是 Muse 的判断，两者共享同一种推理方式。下面 76% 的 A 一致率，有一部分是"同一种脑子想了两遍"，不能当成 A 被证实了。真正的独立检验仍然需要真人审阅。

## 1. 方法

- 4 位裁决者并行，每人 25 题（F01–F25、F26–F50、F51–F75、F76–F100），优先十题（F06、F07、F22、F23、F42、F43、F61、F62、F81、F83）各自先做。
- 每题通读情境 + 四个候选（A 作者推理、B 编码器共振、系统预测、基线 LLM 预测）+ 候选卦的卦文档，独立判断：最能抓住情境中心张力（而非旁支）的起始卦，1–3 条最能表达演化的动爻，落点卦由起始卦按动爻逐位取反算出（阳=1，爻位自下而上 L1..L6），再反向验算一遍。
- 不按多数票、不照抄 A；两可时选理由更贴合中心张力的一方，并在备注写"两可，选X因…"（共 4 题：F05、F56、F73、F79）。
- 来源标注：与某候选起始卦+动爻完全一致才记该来源，否则记 custom。本次 custom 为 0，system 为 0。
- 100 条全部写入 Space（`save_adjudication`，逐题调用，100/100 成功），导出核对与文件一致；`exam_100.json` 及原有标签未改动。

## 4. 怎么读这些数字——循环性警告

**对照 Pass C 的分数，很大程度上是在量"各来源被采纳了多少次"，不是独立准确率。** 因为 Pass C 就是从这四个来源里挑出来的：

- Pass C 采纳 A 76 次，所以 A 与 Pass C 的 76/100 完整一致是构造使然，不是证据。
- 基线的 17 个完整路径里，有 16 个是 Pass C 本来就采纳了基线的动爻；只有 F21 是采纳 A 的题、基线恰好也对上了。基线路径分从 1→17 的跃升，基本等于"被采纳了 16 次"，不能读作"基线会推理演化了"。
- 相对干净的一组数字是系统的：系统 0 次被采纳，所以系统对 Pass C 的 15/25/3 不含采纳偏差——它确实比对草稿标签时（10/21/1）好了一点，但仍在低位；路径 3/100（F02、F13、F46），动力学依然没做出来。

真正非循环的发现是这两条：

1. **基线 LLM 的"理由"和它自己的答案几乎总是对不上。** `baseline_100.json` 的 `end_agrees_with_llm` 字段：100 题里有 90 题，LLM 在理由文字里点名的落点卦，与它自己算出的落点卦不是同一个（五类均匀分布：19/18/18/18/17）。基线的 34/100 top-1 更像是模式匹配，而不是它文字里讲的那套推理。它的结构化答案可计分，它的叙述理由不可信。
2. **日常类 20 题没有任何一方走对路径。** 创意类系统 top-1 只有 1/20，是系统最弱的一类；基线在创意类反而最好（9/20）。

## 5. 诚实边界

1. **Pass C 不是独立人工复核。** 单一模型家族的一次裁决；A 与 C 的 76% 一致里有共享推理方式的成分。标签集现在是自洽的（一个裁决者、100% 覆盖），但没有被独立验证过。
2. **对照 Pass C 的分数有循环性**（见第 4 节）。不要用"基线 34/100"去宣称 LLM 赢了，也不要用"系统 15/100"去宣称系统进步了——这两个数字的基准本身就是从这四个来源里挑出来的。
3. **"动爻"依然是全线最难的部分。** 即使在 Pass C 自己的标签里，动爻也只有 1–2 条（没有 3 条的），且 4 题明确标记两可。情境→动爻的映射标准仍然模糊。
4. **下一步真正需要的是真人审阅。** 至少抽查 Pass C 里采纳 A 的 76 题和采纳基线的 16 题，看人类是否认同；或者等用户有空时自己过一遍 Space 里的裁决（可覆盖修改）。在那之前，不要再拿这套标签去拟合动力学权重——那会是 Phase 2 过拟合的翻版。
