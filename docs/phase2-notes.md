# Phase 2 笔记：学习动力学（Learned Dynamics）

**日期：** 2026-11-21
**状态：** Phase 2 完成。VSA 向量化、连续爻、参数化动力学打分器、考试卷子 v2
harness 全部能跑，测试全绿。

Phase 1 的结论是：找"现在像哪一卦"有一半靠谱（top-1 15/30），但"该动哪一爻"
几乎全错（完整路径 2/30）——路径排名只看落点共振，没有方向信息。
Phase 2 回答的问题是：**给一个带方向的打分器，它能不能学会往哪走？**
答案见下——是诚实测出来的，不好看，但有用。

---

## 建了什么

- **VSA 向量化**（`taiji_field/vsa.py`）：每卦一个超向量，`torchhd` MAP 模型，
  D=10,000，固定种子可复现。6 个爻位向量 + 阴/阳两个值向量，卦向量 = 6 个
  `bind(爻位, 爻值)` 的 bundle（逐元素求和）。三角向量同理（3 爻）。
  经验性质（测试锁定）：两卦余弦 ≈ `1 - 汉明距离/6`——汉明 1 邻居 ≈0.83，
  汉明 3 ≈0.5，错卦（汉明 6）≈0。也就是说错卦是**最不相似**（正交），不是
  反平行：阴/阳是两个独立随机向量，不是互为负向量。"对立"在这里的意思是
  "什么都不共享"，这比"互为负数"更符合错卦的直觉。
- **连续爻**（`taiji_field/continuous.py`）：一个态是 6 个 [0,1] 浮点数（每爻
  的阴阳配比），二值卦是连续立方体的角点。软向量 = 每爻 `θ·阳向量 +
  (1−θ)·阴向量` 再求和；θ=0.5 时两向量部分抵消，贡献变弱——最大不确定是一
  个更弱的信号，不是一个第三值。`python -m taiji_field.continuous 1 2`
  在乾→坤之间插值：端点精确还原（cos 1.000），中点到两端等距，翻转点正
  好落在 t=0.5。
- **参数化动力学打分器**（`taiji_field/dynamics.py`）：
  `score = w1·落点共振 + w2·路径连贯 + w3·互卦吸引 − w4·步数`。
  - 落点共振：落点卦文档与情境的余弦（Phase 1 的项）。
  - 路径连贯：路径上相邻两态的文档余弦均值（含起点→第一步）。**有意不用
    VSA 余弦**：VSA 里每个汉明 1 步的余弦几乎恒定（≈0.83，标准差 <0.05，
    测试锁定），排不出"动哪一爻"——没有方向信息。用文档空间量连贯，是
    因为它随路径变化。
  - 互卦吸引：路径经过起点卦的互卦（内核）时 +1。角落：乾、坤的互卦就是
    自身，简单路径无法在起点之后经过它，所以这一项对乾、坤永远不触发。
  - 4 个权重用粗网格搜索拟合（144 种组合），目标是卷子上的路径命中数。
- **考试 v2 harness**（`taiji_field/exam.py --reasoner v2`）：拟合权重 +
  留出检验（两半互换）+ 全卷实测，写 `taiji_field/data/exam_report_v2.json`
  （生成物，不入库）。**绝不覆盖 `exam_report.json`**，两份报告都保留。

## 考试结果（诚实数字，2026-11-21 实测，bge-small-zh-v1.5）

| | top-1 | top-3 | 完整路径 |
|---|---|---|---|
| Phase 1（启发式） | 15/30 | 20/30 | **2/30** |
| Phase 2（样本内，拟合权重） | 15/30 | 20/30 | **5/30** |
| Phase 2 留出：A 拟合 → B 测试 | — | — | **2/15** |
| Phase 2 留出：B 拟合 → A 测试 | — | — | **0/15** |

拟合权重（全卷）：`w1=0.5, w2=2.0, w3=0.5, w4=0.2`。留出两半各自拟合出的
权重并不一样（A 半：`w2=2.0, w3=0.5`；B 半：`w2=0.0, w3=0.0, w4=0.1`）——
权重在两半之间跳变，是过拟合的另一个特征。

**结论：没有证据表明动力学学到了能泛化的方向。** 样本内 2→5 的提升，
留出检验合计是 2/30，和 Phase 1 的 2/30 一模一样。连贯项（w2）在样本内
起了主要作用，但它没有迁移到另一半。按 roadmap 第 6 节的可证伪点来
说，Phase 2 没有证伪整个想法——动力学这一步还没成立，但也没证明它
不可能。30 个单人草稿标签、4 个可调权重，这个实验本来就测不出更多。
下一步要么是更大的卷子（更多标签、3 人共识标注），要么是换一种动力学
（能量函数 + JEPA 式训练，而不是 4 个权重的线性打分）。

## 自查中修掉的一个 bug（值得记下来）

第一版拟合算出的样本内路径命中是 8/30，但 harness 用同一组权重跑出来
只有 5/30。原因是拟合计数只比了"动爻是否相同"，没要求"起始卦是否相同"；
harness 的定义是两者都要对。有 3 道题动爻蒙对了、起始卦是错的，被拟合
数进了 8。已修：拟合目标与 harness 的定义完全一致（起始卦 + 动爻），
并加了回归测试锁定两者相等。教训：**拟合目标和评测定义必须同一段代码
路径**，否则拟合就是在优化一个没人评测的东西。

## 诚实边界（读代码之前先读这段）

1. **权重是调出来的，不是学出来的。** 30 个标签、4 个权重、144 种组合
   的网格搜索。留出检验已经说明它不泛化。不要把拟合权重当成"学到的动力学"。
2. **标签还是草稿。** 30 个提议演化是 1 个人定的，0 轮共识。用户在
   2026-11-21 明确说不用他审、按自检推进——这是他的决定，但不改变标签
   本身没审过的事实。命中率低可能说明动力学不行，也可能说明标签不行。
3. **连贯项用的是文档空间，不是状态空间。** 路径连贯量的是"经过的卦的
   解读文本像不像"，不是态本身的几何。这是 v2 的务实选择，不是原理。
   真正的状态空间连贯（VSA 余弦）排不出方向，见上。
4. **解释器没变。** 输出的"为什么"仍然是 Phase 1 的模板（动了哪一爻 +
   两端卦的一句解读）。动力学打分器只决定走哪条路，不解释为什么。
5. **LLM 基线仍然没做。** 和 Phase 1 一样，报告格式预留了 `baseline`
   字段（目前为 `null`）。没有基线，"赢没赢过 token 预测"依然无法判定。
6. **torchhd 的一个坑（已解决，记下来免得后人再踩）：** `torchhd.bundle_sequence`
   不是普通求和——它先把每个元素置换（`Π^{n-i-1}`）再求和，是序列编码。
   普通多路 bundle 要用 `torchhd.multiset`。第一版用了 `bundle_sequence`，
   测试立刻抓住了（三角向量与所属卦的余弦 ≈0 而不是 ≈0.7）。

## 怎么跑

```sh
pip install -e ".[dev]"   # 新增依赖 torch-hd（VSA）

# VSA 与连续插值
python -m taiji_field.continuous 1 2 --steps 5

# Phase 2 考试：拟合权重 + 留出检验 + 全卷实测
python -m taiji_field.exam --reasoner v2
# 只跑前 2 题（拟合与留出都在子集上跑，仅供冒烟）：
python -m taiji_field.exam --reasoner v2 --limit 2

# 测试
pytest
```

## 自我 code review（标准 + 规格）

- **标准：** 新模块按职责分开（vsa / continuous / dynamics），推理与解释
  继续分离；位约定沿用 Phase 0（阳=1、阴=0，L1..L6），没动 Phase 0/1 的
  代码；`exam.py` 的 v1 路径行为不变（默认 `--reasoner v1`，原有测试全绿）。
- **规格（对照 roadmap Phase 2）：** VSA 向量化 ✓（torchhd，D=10,000）；
  连续爻 ✓（配比 θ，插值 demo）；从（情境，演化）数据对里学能量函数/
  转移模型——**部分**：做的是 4 权重线性打分器的网格拟合，不是 JEPA 式
  训练；能量函数 E（态）没有显式学出来，打分器只在路径层面打分。评测
  升级 ✓（留出检验 + v2 报告），但卷子还是 30 题草稿标签。
- **一个偏离：** 任务要求里"路径连贯"没有指定向量空间，我选了文档空间
  而不用 VSA 空间，理由是 VSA 余弦在汉明 1 步上近乎恒定、无法排序——
  这个选择在模块 docstring 和本笔记里都写明了。
