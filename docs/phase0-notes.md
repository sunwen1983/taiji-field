# Phase 0 笔记：64 卦状态图的手动走查

**日期：** 2026-11-21
**状态：** Phase 0 完成。图是真的，测试全绿，三个情境都用 `python -m taiji_field.demo` 实际走过（邻居关系由代码算出，不是凭印象编的）。

走查方法：先给情境定一个起始卦（凭判断，人定的），再沿着图的边走 1 步，看落点像不像"情境的下一步"。每条走查后面都有一句诚实话：哪里顺，哪里别扭。

---

## 情境 1 — 工作决策：手里有个很好的新机会，要不要跳槽？

**起始：䷙ 大畜 #26（Great Taming）**。下乾（实力在手），上艮（山，止）——有牌，但被山压着，现在不是动的时候；或者说，动之前要先蓄势。这个映射我觉得站得住。

**走法 A：动第 6 爻（顶爻）→ ䷊ 泰 #11（Peace）。** 大畜上九的爻辞是"何天之衢，亨"——积累到顶，天路自开。泰是天地交、上下通，正是跳槽后想要的状态：新环境里上下通达。

**走法 B：动第 4 爻 → ䷍ 大有 #14（Great Possession）。** 留在原地，把积累变现——大有是"大有收获"。

**诚实话：** 两条路都通，图没有说哪条更好。图给出的是"可达的状态"，不是"该选哪个"。为什么动第 6 爻而不是第 5 爻（→ 小畜 #9，退回小规模积累）？图不回答，需要人的判断。**这就是 Phase 0 暴露的动力学空白：边是现成的，但"走哪条边"的规则还没有。**

---

## 情境 2 — 谈判僵局：双方谈不拢，卡住了

**起始：䷋ 否 #12（Standstill）**。天地不交，上下不通，经典僵局。这个映射几乎不用论证。

**走法 A：动第 5 爻 → ䷢ 晋 #35（Progress）。** 否九五的爻辞是"休否"——否到极处，君位一动，局面开始向上走。晋是"明出地上"，太阳升起来。这一步很顺：僵局里只要高位的人松动一点，局就活了。

**走法 B（作弊走法）：错卦 / 综卦直达泰 #11。** "否极泰来"人人会说，但图里否到泰没有单步直达——汉明距离是 6，必须经过中间态。把六爻全翻当成"一步"，是成语在作弊。

**诚实话：** 这一步走查反而是图最有价值的地方：它把成语掩盖的东西说清楚了——"否极泰来"中间必须有人先让一步，泰不是凭空来的。别扭的地方：动第 2 爻 → 讼 #6（冲突），动第 3 爻 → 遁 #33（撤退），都是"更糟"的方向；图不阻止你往坏处走。**没有能量函数，就没有"下坡"的方向。** 这是同一个动力学空白的另一面。

---

## 情境 3 — 个人选择：深夜了，是继续刷题还是休息？

**起始：䷜ 坎 #29（The Abysmal）**。重坎，习坎，一坑接一坑地刷题，越刷越深。这个映射我觉得贴切，但也承认：换一个人可能把它映射到困 #47 或大过 #28。**接地的映射没有客观标准，这是第二大空白。**

**走法 A：动第 3 爻 → ䷯ 井 #48（The Well）。** 井是"改邑不改井"——水在底下，取之不竭。休息不是放弃，是让井水重新蓄满。

**走法 B：动第 1 爻 → ䷻ 节 #60（Limitation）。** 节是"节制"，知道什么时候停。

**最有意思的一步：互卦 → ䷚ 颐 #27（Nourishment）。** 坎的内核是颐——问题的核心其实是"靠什么养自己"，不是"刷多少题"。互卦挖出了情境的内核，这是单步变爻给不了的东西。

**诚实话：** 从坎到井要动第 3 爻，为什么是第 3 爻？凭什么不是第 1 爻的节？图给不出理由——"哪一爻动"这个选择本身没有规则。两条路都合理，等于都没说。**动力学空白第三次出现。**

---

## 小结：什么成立，什么没成立

**成立的：**

- 图是真的。64 节点、变卦 192 条边（Q6）、错卦 32 对、综卦 28 对 + 8 自对称、互卦像集恰好 16——全部由测试锁定，且与数据集自带的 opposite/inverted/nuclear 字段逐条交叉验证过。
- 走查能推出真正有启发性的路径（否→晋的"高位松动"、坎→颐的"内核是滋养"），不是纯粹的附会。错卦/综卦/互卦挖出的结构，是单看卦辞看不到的（例如否的错卦与综卦恰好重合在泰）。
- 验证过程本身证明了交叉检查的价值：我一度把巽/兑两卦的爻位记反了，是数据集的姤/夬两卦（初六、九二……的爻位）纠正了我。测试拦住了人的错误，这是好事。

**没成立的（和 roadmap 第 7 节的风险清单一致）：**

1. **动力学空白（最大）：** 三个情境都卡在同一个地方——"走哪条边"没有规则。没有能量函数，就没有方向。
2. **接地空白：** 情境→卦的映射靠人工判断，没有客观标准。不同的人会定不同的起始卦。
3. **没有"该选哪个"的答案：** 图是地图，不是导航。导航需要动力学 + 接地，两者现在都没有。

**Phase 0 结论：** 骨架作为"结构"被验证了，作为"智能"还没有。这正符合 roadmap 的退出条件判断——可以带着清醒的认识进入 Phase 1（接地与共振），而不是假装问题已经解决了。
