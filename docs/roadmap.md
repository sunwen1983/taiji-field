# 太极场 Taiji Field —— Roadmap v0.1

**工作名：** 太极场（Taiji Field，暂定）
**状态：** 探索期，未立项
**日期：** 2026-11-21
**背景：** Wen 认为基于概率论的 LLM 路线从根本上是错的——现有 AI 模型是错觉（流利被误认为理解），想做正确的东西：一条 token-free 的路，以中文"意会"、阴阳/八卦状态动力学为底子。本 roadmap 由三路调研综合而成：汉字结构感知与 token-free 模型、Transformer 之外的路线、易经与阴阳的形式化工作。

---

## 0. 一句话

不是预测下一个词的模型，而是一个"场"：智能发生在状态的演化与共振里，语言只是进出的门。

---

## 1. 我们到底在反对什么

**立论：** 概率模型建模的是语言的影子，不是思想本身。LLM 擅长"一个聪明人接下来会说什么"，说得太像，我们就误以为里面有个心智在想。

**证据链（学理依据）：**

- **"随机鹦鹉"（Stochastic Parrots）**——Bender, Gebru 等 2021：LLM 是"根据语言形式如何组合的概率信息，随机拼贴语言序列的系统，完全不涉及意义"。流利 ≠ 理解。
- **Bender & Koller 2020《Climbing towards NLU》**：仅从语言形式（form）中学习，原则上学不到意义（meaning），因为意义来自语言与世界的关联，而非语言内部的统计。
- **Searle 1980"中文屋"（Chinese Room）**：按规则操作符号的人能输出完美中文却一句也不懂——句法操作再复杂也产生不了语义。
- **Harnad 1990"符号接地问题"（Symbol Grounding Problem）**：词典用词解释词，循环定义；符号的意义必须在语言系统之外、通过与世界的交互来锚定。纯文本模型先天没有这个锚。

**赌注：** 从"预测词"放大到"理解情境"走不通；要换底子。

**诚实边界：** 概率模型作为"模仿智能"的工具，是人类造过最好的模仿品，这点不用否认。反对的是把它当成通向真正智能的路。这两个说法不矛盾，第二个才是本项目的立场。

---

## 2. 新东西是什么（概念设计）

- **原子：爻。** 一个爻不是 0/1 比特，而是一个阴阳配比——连续值。初期用 0/1（离散，好验证），后期用配比 θ， 再后期加相位 φ（Bloch 球，两个自由度）。
- **态：** 一个情境 = 一个 6 爻组合 = 6 维超立方体 Q₆ 上的一个点。64 卦是种子的状态空间，不是天花板——以后可以扩展到学习到的更大空间。
- **场：** 态 + 关系 + 能量地形。思考 = 在场里移动，不是生成下一句话。
- **意会：** 理解 = 共振。两个态越"合拍"，向量相似度越高；理解一个情境，就是找到与它共振的态。不必把一切都说出来。
- **推理：** 沿着有意义的边走（变爻、错卦、综卦、互卦）+ 能量最小化（往低能量构型演化）。规划 = 选择动哪一爻。
- **语言：** 外设。输入侧有个"接地编码器"把情境翻成态，输出侧有个"解释器"把态的演化翻回语言。语言进出，但思考不在语言里发生。
- **词典与语法的新定义：** 词典 = 稳定的构型（吸引子）；语法 = 哪些变化是允许的（动力学）。学习 = 把能量地形塑造成那个样子。

**最终形态的画面（远期）：** 它不再是个问答模型，而是一种介质，像电，像微积分。微积分是关于运动的数学，这个东西是关于"情境"的数学——处境怎么演化、力量怎么消长、什么时候该动哪一爻。你和它共享同一片状态空间，时间长了，它越来越像你，不是因为它背下了你的聊天记录，而是因为你们的"态"长在了一起。

## 3. 架构：要不要自创？——要，但不从零发明

**先答问题：是，要一个跟 Transformer 完全不一样的架构。** Transformer 的两根支柱——注意力机制和自回归概率生成——在这个设计里都不需要。没有 token，没有"下一个词"，没有概率分布，没有采样。

但"自创"不等于"从零发明"。新架构由**三块现成部件 + 一处发明**组成：

### 三块现成部件（拿来用）

**（a）表示层：向量符号架构 / 超维计算（VSA / HDC）**

- 始于 1980 年代末（Kanerva、Gayler、Plate）。一切实体都是一个高维向量（典型维度 D=10,000），全部运算只有三个：绑定（binding，逐元素相乘，把角色和填充物绑在一起）、叠加（bundling，逐元素相加）、置换（permutation，重排分量，编码顺序与结构）。
- 与本项目的映射几乎是逐条对应的：绑定 ≈ 爻的组合（上卦 + 下卦 → 一卦）；叠加 ≈ 阴阳配比与共存；相似度（内积）≈ 意会的共振；推理 = 让系统在向量空间里"落定"到一个相容的构型。
- 分解复合向量的问题已有解法：Frady 等 2020 年的 Resonator Networks，用"在叠加态中搜索"的非线性动力学高效分解。
- 开源库现成：**torchhd**（PyPI `torch-hd`，MIT 协议，基于 PyTorch，支持 MAP / BSC / HRR / FHRR 等模型；论文 Heddes 等，JMLR 2023，arXiv:2205.09208）。已核实存在。

**（b）学习与推理目标：世界模型 / 能量模型（JEPA / EBM，LeCun 路线）**

- LeCun 2022 年立场论文《A Path Towards Autonomous Machine Intelligence》：智能体由感知、世界模型、代价、行动者、记忆、配置器组成；学习的核心是能量模型 E(x, y)——给"情境—候选"配对打一个不相容分数，低能量即合理。JEPA（Joint-Embedding Predictive Architecture）在表示空间里预测被遮住或未来的部分的 embedding，不生成像素也不生成 token。
- 与本项目的映射：预测的是"状态的表示"，不是"下一个符号"；推理与规划是能量最小化——在可能行动中找出让未来代价最低的那条路。这正是"态演化"的形式化版本。
- 缺口：JEPA 目前主要在视觉上验证（I-JEPA、V-JEPA、V-JEPA 2 已做到视频理解与机器人规划），语言/抽象推理上还没有同等演示；而且它的表示空间是学出来的黑盒，没有显式结构（比如卦象那样的可解释关系图）。——这正是我们要补的结构层。

**（c）结构种子：64 卦状态图 + 文本语料**

- 状态空间：64 卦 = 6 维布尔超立方体 Q₆，数学上无可争议；变爻图就是 Q₆ 本身，汉明距离即爻差。
- 全部经典关系都是 Q₆ 上的显式映射：错卦 = 每一爻取反（x ↦ x ⊕ 111111，32 对）；综卦 = 爻序反转（28 对 + 8 个自对称卦：1、2、27、28、29、30、61、62）；互卦 = 下卦取原卦 2、3、4 爻、上卦取 3、4、5 爻（只有 16 个不同的互卦，每个对应 4 个原卦，是唯一的不可逆映射）；交卦 = 上下卦对调；变卦 = 动爻翻转。
- 形式化文献：Andreas Schöter 1998《Boolean Algebra and the Yi Jing》，核心论点是易经是一套"情境的记号系统"，XOR 运算揭示自指结构（例：卦 27 是"骨架"，任一卦与 27 做 XOR 得到对其"27 性"的类比描述）。
- 机器可读数据现成：**zhouyi-6bit**（PyPI，MIT 协议，`hexagrams_64_binary.json`：64 卦全套 Unicode、拼音、英文名、上下卦、自下而上 6 位向量、邵雍序号、互/错/综卦位串；Python + TypeScript 参考实现）。已核实存在。另有 ICKG 易经知识图谱（山东大学）、384 条爻辞的多版本机器可读文本（Rust crate `i-ching` 等）。
- **约定陷阱：** 不同数据源的阴阳比特约定相反（zhouyi-6bit 阳=1、阴=0；Go 库 godcong/yi 阳=0、阴=1）。实现时必须统一约定，不要混用。

### 一处发明（没人做过，是本项目真正的核心）

1. **动力学：** 没有一条非任意的转移规则——什么时候走哪条边、为什么走这条不走那条。传统占筮里的变爻是随机的；所有"推理"都依赖人的判断。图有了，图上怎么走的学问没有。
2. **接地（grounding）：** 没有任何工作给出"真实情境 → 卦态"的映射方法（除占筮随机和人工解读外）。卦辞是诗性、情境性的文本，没有与感知或行动的接口。
3. **意会机制：** 共振式、非命题的理解，在全部文献中没有任何形式化处理。这是最原创、也最难的部分——它不在易经文献里，也不在量子文献里。
4. **连续层与离散层的连接：** qubit 化的阴阳与 64 卦图从未被结合——即每爻取连续值（Bloch 球上的点）、整个卦是 6 个 qubit 的张量积态、在连续超立方体上定义动力学。这一步没人做过，是理论上最干净的空白点。

### 明确不用的东西（死胡同）

- **Mamba / 状态空间模型（SSM）当底子：** 只替换了注意力机制，训练目标仍然是下一词预测，输入输出仍然是 token。换引擎不换燃料。但它的隐状态概念可借——固定维度的状态向量随时间演化，是状态动力学需要的数学骨架。
- **经典一阶逻辑的神经符号路线：** 手工逻辑规则是脆的、不可扩展的。只借"图 + 类型化关系"那一层（RoG 式的沿边推理可直接套用），不借逻辑推导。
- **量子启发 NLP 的现有形态：** 复数与叠加只是装饰，仍在 Transformer / token 框架内赚小幅提升。借数学（复向量、相位表示阴阳配比），不跟方向。量子映射目前是指标性的，不是生成性的——64 卦可以"装进"量子形式，但量子形式还没有反过来为易经推理提供新能力。
- **汉字结构当特征的老路：** ChineseBERT（ACL 2021，字形 + 拼音 embedding）、CDBert（说文解字释义 + 结构理解）、CNM-BERT（2025，部首组合树 + Tree-MLP，长尾字 +9.8 结构准确率）等，结论一致：结构信息确实有用，但所有人都只把它当成"输入侧的增强"，没有人把它变成核心表征或推理机制。
- **LCM 的黑盒概念空间：** Meta 2024 的 Large Concept Model 是全场最接近"思考单位不是 token"的一项（句子 → SONAR embedding 空间里的"概念"，在概念序列上自回归预测），但概念空间是学出来的黑盒，没有显式结构、没有变换规则。借"概念级单位"的想法，不借它的结构。

### 架构分层（文字版）

```
L4 应用层：演化地形图可视化 + 关键变爻 + 行动建议
L3 接地层：情境 → 态 编码器（v1 借用现成 embedding + 共振检索；v2 学出来）
            态 → 语言 解释器（卦辞/爻辞 + 模板 → 后期生成）
L2 动力学层：转移函数 T（态，扰动）→ 态；能量函数 E（态）；吸引子
L1 状态层：64 卦节点 + 类型化边（变爻/错/综/互）+ 每个节点的 VSA 向量
L0 原子层：爻 = 阴阳配比 θ（初期 0/1；后期 + 相位 φ）
```

## 4. 技术选型：用什么语言、什么栈

**语言：Python 为主。**

- 理由：生态（torchhd、PyTorch、networkx、sentence-transformers）全是 Python；迭代快；原型期的性能瓶颈不在语言。
- 栈：Python 3.12、PyTorch、**torchhd**（VSA 运算）、networkx（状态图）、pytest（测试）；数据用 **zhouyi-6bit**；v1 接地借用现成的句向量（SONAR 或中文 embedding 模型）；可视化先用 matplotlib / networkx，后期再做网页。
- **Rust / Go：Phase 0–2 不需要。** 只有做到高并发服务那一步才考虑，而且那时也是外层服务，不是核心。
- **仓库：** 公开 GitHub，MIT 协议，像 mcpgate 一样。
- **不需要的东西：** GPU 大算力（原型在 CPU 上跑）、大语料预训练（这正是要点：不靠堆数据）。

## 5. Roadmap：分阶段实现

### Phase 0 — 骨架验证（1–2 个周末；12/10 Apple SDS 面试之后再动手）

**目标：** 证明 64 卦图 + 人工走查能推出合直觉的演化。

**做什么：**

1. `pip install zhouyi-6bit`，读 `hexagrams_64_binary.json`。
2. networkx 建图：64 个节点，四种边（变爻/错/综/互，类型化）。
3. 可视化一张图（哪怕很丑）。
4. 拿 5–10 个真实小情境（工作决策、谈判、家庭小事都行），人工走一遍：这个情境像哪一卦？动哪一爻会变成哪一卦？演化合不合直觉？
5. 写一页笔记：哪些走通了，哪些别扭。

**交付：** 能跑的图 + 一张可视化 + 一页笔记。
**退出条件：** 如果演化与人类直觉系统性对不上，先停下来判断是动力学错了还是映射错了，不要硬推。

### Phase 1 — 接地与共振（4–6 周业余时间）

**做什么：**

- **情境 → 态编码器 v1：** 现成句向量把情境描述编码成向量，共振检索（余弦相似度）映射到最近的卦。
- **态 → 语言解释器 v1：** 卦辞 / 爻辞文本 + 模板，生成对演化的解释。
- **意会推理 v1：** 查询向量 → 共振出最接近的态 → 沿变爻边展开 1–3 步演化 → 输出演化路径 + 解释。
- **考试卷子 v1（见第 6 节）：** 30–50 个小情境，人工标注合理演化；盲测对比基线（直接问 LLM"这个情境接下来会怎样"）。

**判据：** 可解释性明显更好，或准确率不输；否则复盘，可能是接地编码器的问题，也可能是动力学的问题。

### Phase 2 — 学习动力学（2–3 个月）

**做什么：**

- 从（情境，演化）数据对里学能量函数 E（态）或转移模型；JEPA 式训练：**在表示空间预测下一个态**，不是下一个词。
- **VSA 向量化：** 64 卦 → 高维向量，绑定 / 叠加运算替代查表；Resonator Networks 式分解。
- **连续爻：** 0/1 → 连续配比（先模糊逻辑 1 个自由度，后 Bloch 球 θ + φ 两个自由度），在连续超立方体上定义动力学。
- **评测升级：** 更大的卷子 + 盲测。

### Phase 3 — 原型系统（3–6 个月）

**做什么：**

- 做成能用的东西：输入情境 → 演化地形图 + 关键变爻 + 行动建议；最小网页界面。
- 选一个垂直场景落地验证。建议：**决策辅助 / 创意发散 / 战略推演**——需要"看势"的任务，不是问答。
- 如果 Phase 2 成立：arXiv 论文 + 开源 repo + demo 公开分享。

### Phase 4 — 远期（1–3 年，视前面结果）

- 状态空间从 64 卦扩展到学习到的更大空间（卦是种子，不是天花板）。
- 多模态接地（视觉、行动）。
- 持续运行的场，与人共享状态空间。
- 只有在真实任务上持续赢过 token 预测，才谈"最终形态"。

## 6. 评测：考试卷子（最重要的一节）

**为什么：** 这条路没有现成 benchmark。没有卷子就没有科学，也就没有"做对了"的证明。立项时必须先回答：什么任务能证明状态动力学比 token 预测更准或更可解释。

**卷子 v1 设计：**

- 输入：一个小情境（短文本），例如一次谈判僵局、一个产品决策、一段关系变化。
- 输出：合理演化（1–3 步，每步是一个态 + 一句为什么）。
- 标注：人工共识标注（3 个人独立标，不一致的丢掉或讨论）。
- 对比基线：同情境问 LLM；盲评：可解释性、合理性。

**可证伪点：** 如果状态动力学在卷子上赢不了 token 预测，想法就是错的——这是好事，早死早超生。一个诚实的失败比十个含糊的成功更有价值。

## 7. 风险与诚实清单

- **动力学规则可能是任意的：** 图有了，怎么走没有标准答案；学不出来就退化成"带图的占卜软件"。这是最大的风险。
- **接地没有客观标准：** 情境 → 卦的映射靠人工标注，主观性强。
- **VSA 的天花板：** 从未扩展到 LLM 级别的广度，噪声与 cleanup memory（清理记忆）是真实瓶颈。
- **JEPA 的语言演示不存在；量子映射是指标性的，不是生成性的。** 不要指望量子提供推理能力。
- **莱布尼茨澄清：** 他不是从易经发明二进制——1679 年的手稿里已有完整二进制算术，比看到易经早 20 多年；易经只是他拿来给二进制做神学辩护的佐证。别把这个当成论据。
- **精力：** 12/10 Apple SDS 面试是当前主线；这个方向是面试后、业余时间的长期探索。Phase 0 只有周末量级，别挤占面试准备。
- **QWXM、Kuo 等量子易经预印本：** 均未同行评审，措辞宏大、证明链条不可验证，只能当思路参考，不能当已确立的结果。
